Επεξεργασία επισκόπησης

The section selector replaces desktop tabs. This example is in read mode. Edit mode exposes explicit Save and Cancel actions.

Other views: contributors keep this record structure with granted Upload and Add Log actions only. Share recipients see the read-only structure without navigation to other records. Both omit private groups entirely. The Plan 5 implementation plan specifies decisions, measurements, uploads, viewers and access behavior.
